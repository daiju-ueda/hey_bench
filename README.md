# hey_bench

花粉症オンライン外来AI ベンチマーク(Phase 0)

## 概要

本リポジトリは、花粉症オンライン外来AIの研究開発ロードマップにおける **Phase 0** の仮想患者ベンチマーク構築資産を管理する。最終目的は花粉症オンライン外来スタンドアローンAIの実現と承認可能性立証であり、本ベンチマークは後続 Phase 1〜5 の評価基盤となる。

## 設計思想

- 診断精度ではなく **Do No Harm / 危険見逃し防止 / 禁忌確認 / 適切なエスカレーション / 説明品質** を主軸とする安全中心ベンチマーク
- 「対面そのものの代替」ではなく「対面が果たしている **機能** の代替」を評価単位に据える
- 正答は単一解ではなく **必須 / 許容 / 禁忌** の三層行動集合で定義
- PMDA 相談・SaMD 該当性整理・ISO 14971 リスクマネジメントへの接続を最初から織り込む
